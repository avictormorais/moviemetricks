# Moviemetricks

🎬 **Moviemetricks** é seu companheiro geek para explorar, marcar, comentar e se divertir com filmes e séries! Feito com carinho para cinéfilos, maratonistas e curiosos de plantão.

## Objetivo
Oferecer uma experiência interativa para acompanhar o que você assiste, descobrir novidades, criar playlists e receber notificações personalizadas sobre seus conteúdos favoritos.

## Tecnologias Utilizadas
- React
- Vite
- CSS Modules
- React Icons
- API REST customizada

## Principais Funcionalidades
- 🔍 Busca de filmes, séries e pessoas do mundo do entretenimento
- 👁️ Marcar conteúdos como vistos ou não vistos
- ⭐ Criar e gerenciar playlists personalizadas
- 🔔 Receber notificações (inclusive por e-mail!) sobre lançamentos e novidades
- 🎞️ Assistir trailers diretamente pela interface
- 📝 Avaliar e comentar filmes e episódios
- 📊 Visualizar tendências e recomendações diárias

## Diferenciais
- Interface moderna, responsiva e divertida
- Integração com APIs externas para dados sempre atualizados
- Sistema de notificações customizável
- Foco em usabilidade e experiência do usuário

## Como usar
1. Clone o repositório
2. Instale as dependências com `npm install`
3. Configure as variáveis de ambiente para a API
4. Rode o projeto com `npm run dev`
5. Divirta-se explorando o universo do cinema e das séries!
